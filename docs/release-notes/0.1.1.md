Fix release for Mac Stats 0.1.0.

## Fixed

- **Clicking a menu bar item showed nothing.** The menu opened with a size of zero. It now opens at its real size.
  A new automatic test opens the menus on a Mac in CI on every change, so this cannot slip through again.

## Added

- **Open Settings without the menu bar.** Open Mac Stats again while it runs (double-click it in Applications, or use
  Spotlight or Launchpad), or run `open macstats://settings` in Terminal.

- **Logging.** If something goes wrong, collect the app's log in Terminal and share it:

  ```
  log show --last 30m --info --predicate 'subsystem == "app.macstats.MacStats"'
  ```

  The log holds only app internals (item names like `cpu`, panel sizes, counts). It never holds process names or file paths.

## Known limits

Same as 0.1.0: ad-hoc signed and not notarized (right-click → Open, or System Settings → Privacy & Security →
Open Anyway on macOS 15+), no auto-update, per-app network and GPU are experimental.
